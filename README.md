##DISCLAIMER : This only works on Linux/Unix.##
This is an offline wikipedia client built in Java, it only contains the contents of simple.wikipedia.com to make it more lightweight.
To setup, download the latest release, unzip wikipedia.tar.gz and place wikipedia.txt in your home directory.
Thanks to ffatty on Kaggle for providing the file for anybody to use (https://www.kaggle.com/datasets/ffatty/plain-text-wikipedia-simpleenglish?resource=download)
